# 新电脑图形化配置并启动

## 已确认需求

面向 Windows 新手。双击一个入口，首页默认第三方自定义 API；填写名称、API 基础地址、模型和 Key，点击一次“配置并启动”。自动完成运行环境检查/安装、独立实例配置、创建以后使用的入口并打开 Claude Code。保留已有实例隔离及命令行入口，不替用户绕过系统授权、Claude 首次许可或项目信任确认。

## 实现

- 使用 Windows 自带 PowerShell 5.1 + Windows Forms，不引入浏览器服务或 Node GUI 依赖。
- `开始使用.bat` / 不带参数的 `setup.bat` 打开表单。顶部选择已有实例或新增；默认填写自定义 API，Key 密文显示；已有实例留空 Key 表示保留。
- 名称、地址、模型和 Key 为主要输入；存储位置、项目目录在更多选项中。一个主按钮执行完整流程，后台安装时不阻塞窗口。
- GUI 将 Key 用 Windows DPAPI（当前用户）加密。后台请求文件和 `api-key.dpapi` 均不含明文 Key；命令行、状态输出和安装日志不出现 Key。CLI 旧 .env 方式继续可用。
- 后台仅通过已验证的参数保存配置；失败可重试，不能覆盖不属于所选实例的目录。已有会话、工作文件始终保留。
- 增加主脚本 `-PrepareOnly`：准备运行环境但不进入交互会话。准备成功后 GUI 启动可见终端，创建桌面快捷方式；快捷方式失败不阻塞直接启动。
- 原生安装参考已审阅的官方 install.ps1：固定 HTTPS 下载域名、严格版本格式、manifest SHA256 校验后执行二进制安装。缓存路径显式控制，现有 Node/npm 链只作后备。不会下载执行未知 PowerShell 内容。
- 成功表示已准备并打开进程，不冒充 API、模型、工具调用已验证。GUI 仅提供 Anthropic 兼容接口；OpenAI 实验转换继续走旧入口。
